# Pin GIM SMI (libgimsmi) dependency to 8.7

- **Date:** 2026-06-09
- **Author:** Bhanu Kiran Atturu
- **Related PR(s):** #<number>
- **Related issue(s) / JIRA:** Slack request (Praveen Kumar Shanmugam) — align the MxGPU-Virtualization dependency with the GIM version we are on (8.7), high priority

## Context

DME consumes the GIM SMI library from `amd/MxGPU-Virtualization` as the
`libgimsmi` git submodule (used to build `libgim_amd_smi.so` for the SR-IOV
exporter image).

Before this change the pin was internally inconsistent:

- `libgimsmi` submodule gitlink was at **`mainline/8.3.0.K`** (`1d4d538`),
  set by #1040.
- `.gitmodules` tracking branch pointed at the floating `mainline` branch.
- `Makefile` `GIMSMI_COMMIT` referenced **`mainline/8.7.0.K`**, a tag that no
  longer exists in the upstream repo (the real 8.7 tag is `8.7.0.K`, with no
  `mainline/` prefix) — so the build var did not resolve.

Per the request, pin the dependency to the **8.7** release we are actually on
and use a real, resolvable release ref instead of a floating/broken one.

## Approach

DME-only change. Pin the dependency to the immutable 8.7.0.K release tag and
align the build vars:

- `libgimsmi` submodule gitlink: `mainline/8.3.0.K` (`1d4d538`) → **`8.7.0.K`**
  (`a5faf31`).
- `.gitmodules` tracking branch: `mainline` → **`release/8.7.0.K-rc`**.
- `Makefile`: `GIMSMI_BRANCH` → `release/8.7.0.K-rc`, `GIMSMI_COMMIT` →
  `8.7.0.K`.

Note: the `release/8.7.0.K-rc` branch head has advanced to the `8.7.1.K` patch
(`4237f02`); the submodule gitlink is pinned to the base `8.7.0.K` tag for a
reproducible build, while the tracking branch follows the 8.7 rc line.

## Scope

- **In scope:** `libgimsmi` submodule pin, `.gitmodules` tracking branch,
  Makefile `GIMSMI_*` build vars.
- **Out of scope:** gpu-agent changes; rebuilding/committing the prebuilt
  `assets/gim_smi_lib/.../libgim_amd_smi.so`; SR-IOV image build and hardware
  testing.

## Validation

- `git submodule status libgimsmi` resolves to the `8.7.0.K` tag commit
  `a5faf31`.
- The 8.7 GIM SMI lib compiles cleanly from the new submodule pin via the
  RHEL9 builder (`gimsmi-builder:rhel9`), producing `libgim_amd_smi.so` and
  `amdsmi.h`.

## Risks and rollback

- **Risk:** low — 8.7 is the GIM version DME/gpuagent are aligned on. This pin
  mainly removes the prior 8.3-pin / broken-8.7-Makefile-ref inconsistency.
- **Rollback:** revert the submodule/`.gitmodules`/Makefile change (single
  squashed commit), restoring the prior 8.3.0.K pin.
